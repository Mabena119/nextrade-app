iPhone & iPad

Add the web app to your Home Screen in Safari.

Open the new icon, then enable notifications if asked.

Mac

Mac — Safari Add to Dock

Install NexTradeAI as a Dock app in Safari on macOS.

1

Open the web app in Safari.

2

In the menu bar, choose File → Add to Dock….

3

Confirm the name and URL, then click Add. An icon appears in your Dock and Launchpad.

4

Open it from the Dock and sign in with your licensed email / mentor key.

Windows · Chrome

PC — install as a Chrome web app

Use Google Chrome on Windows, Mac, or Linux to install NexTradeAI like a desktop app.

1

On your computer, open Chrome.

2

Open the NexTradeAI web app.

3

At the top right, select More (⋮) → Cast, save, and share → Install page as app…. On some sites, use the Install icon in the address bar.

4

Follow the on-screen prompts. NexTradeAI opens in its own window from your desktop or launcher.

5

Sign in with your licensed email / mentor key.

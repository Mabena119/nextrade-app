NexTradeAI Admin — MT5 .ex5 Update Popup

Modal popup • Auto-dismiss 15s • Once per session

Deploy to https://auraai-vps.com/admin/

1. Copy snippets/mt5-update-toast-embeddable.php to your server (or paste its contents).
2. Include it in admin/home/index.php before </body>.
3. (Recommended) Set $_SESSION['show_mt5_update_popup'] = true; in your login handler, then wrap the include with the session guard shown in the PHP file header.

Update your MT5 .ex5 file
Signals will not work until you replace the Expert Advisor (.ex5) on MetaTrader 5 and update the NexTradeAI app.
  • Download the latest .ex5 from your admin panel
  • Copy it into MT5 → File → Open Data Folder → MQL5 → Experts
  • Ask clients to update the NexTradeAI app from the store
